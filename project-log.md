## 2026-01-13
- **Project Kickoff**:
    - Started the project with the goal of turning the "101 Creative Ideas on Using AI in Education" PDF into a searchable database and a platform for contribution.
- **High-Level Plan**:
    1. Convert PDF to text/markdown.
    2. Parse content into a `.json` database.
    3. Build a website to display and manage the data.
- **Initial Conversion Attempts**:
    - Tested several tools: Google Gemini, `pandoc`, `pdftotxt`, `pdf2htmlEX`, and `Markitdown`.
    - Explored `Docling` via Claude suggestions; installed and converted PDF to Markdown.
    - **Outcome**: `Docling` output was too large and complex; `pdftotxt` provided a simpler baseline but lacks structural metadata.
- **Environment Setup**:
    - Created the `ai-edu-ideas` project directory.
    - Started using Antigravity for automated parsing and implementation planning.
    - Reviewed the initial implementation plan, tasks, and walkthroughs generated by the AI.
